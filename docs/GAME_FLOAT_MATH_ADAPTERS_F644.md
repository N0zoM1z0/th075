## Native original x87 and ordinary source

The original six 28-byte functions are compact one-float-argument adapters to six distinct real double-argument native math routines. Each full original source function has **12 original x86 instructions**, including normal prologue, reserved `ECX` local stack slot, `FLD dword [EBP+8]` from the actual 32-bit float argument, `SUB ESP,8; FSTP qword [ESP]` to promote to a real 64-bit double call argument, genuine `CALL`, caller cleanup `ADD ESP,8`, and original `FST dword [EBP−4]` to round/store the result while leaving x87 ST(0) live for the return ABI, before the original frame epilogue and `RET`. A normal natural C++ `float __cdecl adapter(float x) { return static_cast<float>(NativeDouble(x)); }` reproduces all of this without assembly or fake compiler locals. The provisional `double`-parameter and `float`-return source grammar is strongly supported by actual x87 argument promotion; the original library function identity and historical source authorship are **not** inferred from an unlinked symbol name.

The complete ordinary C++ source is [`GameFloatMathAdaptersF644.cpp`](../probes/GameFloatMathAdaptersF644.cpp). The independent native PE proof is [`verify-game-float-math-adapters-f644.py`](../scripts/verify-game-float-math-adapters-f644.py), which cold-compiles **ONLY this one affected six-function TU** with pinned normal VC7.1, reads the full original PE native function extent and independently verifies original x86 ordinals, full length and **one physically typed zero-addend source `REL32` COFF record at native offset `+14` per function**. It then resolves **only that exact physical original PE call displacement** into a temporary comparison buffer and demands the **entire 28 native CODE bytes** match the original; all 24 non-field bytes must match directly. It also independently decodes real direct CALL instructions across all **4,351** registered original whole-function CODE extents, excluding separately owned after-RET jump DATA.
