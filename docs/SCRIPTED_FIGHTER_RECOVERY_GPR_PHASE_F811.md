produced fallback roles
`EAX,ECX,EDX` while original default
`0052CB25` uses `EDX,EAX,ECX`.
F811's *real* 0x4C original source

`MOVSX ECX,AX` /
`MOV EDX,[EBP-4]` /
`MOVSX EAX,[EDX+70h]` /
`CMP ECX,EAX`. The original
native default instead requires
`MOVSX EDX,AX` /
`MOV EAX,[EBP-10h]` /
`MOVSX ECX,[EAX+70h]` /
`CMP EDX,ECX`.

**exactly 46 B/16 x86 with the same

relocations or allowed masks.
